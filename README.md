## 📌 Deskripsi Singkat Proyek

Proyek ini bertujuan untuk menganalisis data kebahagiaan dunia berdasarkan beberapa variabel utama, yaitu kepuasan hidup, GDP, dan ketimpangan pendapatan. Analisis dilakukan menggunakan Python melalui Jupyter Notebook dengan bantuan library `pandas`, `matplotlib`, dan `seaborn`.

Hasil analisis divisualisasikan ke dalam beberapa bentuk grafik, yaitu horizontal bar chart, bar chart, scatter plot, boxplot, serta grafik gabungan dalam layout 2×2. Setiap visualisasi dilengkapi dengan insight agar hasil analisis lebih mudah dipahami dan tidak hanya menampilkan grafik mentah.
